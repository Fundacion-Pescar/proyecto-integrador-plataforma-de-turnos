# Landing comercial — Módulo 16

Landing de **venta** de OdontoTurno (HTML + CSS + JavaScript, sin frameworks).

## Incluye
- Hero full-bleed con imagen real del consultorio
- Mensajes comerciales orientados a dueños/recepción
- Beneficios, cómo funciona y planes
- Formulario demo conectado a `POST /api/v1/turnos`

## Cómo probarla

1. Levantá el backend:
   ```bash
   cd backend && npm run dev
   ```
2. Serví la carpeta:
   ```bash
   npx serve landing
   ```
   o abrí `landing/index.html` con Live Server.
